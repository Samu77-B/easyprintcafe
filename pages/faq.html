File Requirements & Technical

We accept the following file formats:

  • PDF: Preferred format for print-ready files
  • AI: Adobe Illustrator files
  • PSD: Adobe Photoshop files
  • EPS: Encapsulated PostScript
  • JPG/JPEG: High-resolution images only
  • PNG: For images with transparency
  • TIFF: High-quality image format

For best results, provide files in CMYK color mode at 300 DPI resolution.

For high-quality printing, images should be:

  • 300 DPI for standard printing
  • 150-200 DPI for large format printing (viewed from distance)
  • Vector graphics are preferred for logos and text

Low-resolution images will appear pixelated when printed. We can help optimize your files if needed.

We can print from low-resolution files, but the quality may be compromised. We'll always inform you if we notice potential quality issues and offer solutions such as:

  • Using our design services to recreate the artwork
  • Suggesting alternative file sources
  • Adjusting the print size to maintain quality
