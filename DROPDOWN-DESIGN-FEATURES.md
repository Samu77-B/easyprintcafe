## 🎬 Animation Details

### **Dropdown Appearance:**
```
Opacity: 0 → 1
Position: -10px up → 0
Duration: 0.3s
Easing: cubic-bezier bounce
```

### **Item Hover:**
```
Background: transparent → orange gradient
Text: dark → orange
Position: 0 → 5px right
Duration: 0.25s
Icon Scale: 1 → 1.2
```

### **Featured Button Hover:**
```
Gradient: dark orange → light orange
Scale: 1 → 1.02
Shadow: none → 0 4px 12px
Transform: 0 → 5px right
```
