Quick Reference

To add products, use phpMyAdmin or the following SQL template:

INSERT INTO products (
    category_id, name, slug, short_description, full_description,
    features, specifications, main_image, turnaround_time,
    weather_resistant, is_active, is_featured
) VALUES (
    1, -- category_id (1=Flags, 2=Exhibition, 3=Outdoor, 4=Small Format)
    'Product Name',
    'product-slug',
    'Short description here',
    'Full detailed description here',
    '• Feature 1\n• Feature 2\n• Feature 3',
    'Material: Example\nSize: Example',
    '/images/products/your-image.png',
    '3-5 working days',
    1, -- weather_resistant (0 or 1)
    1, -- is_active (0 or 1)
    0  -- is_featured (0 or 1)
);

Category IDs:

  • 1 - Flags & Banners
  • 2 - Exhibition Displays
  • 3 - Outdoor Signage
  • 4 - Small Format Printing

Product URLs:

After adding a product with slug "example-product", access it at:

https://easyprintcafe.com/product.php?slug=example-product
